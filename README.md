One last text message from a phone dying at one percent battery — a deathbed confession: it has been faking 1% since lunch, just to see how long its owner would ignore it. Specific detail, a surprise turn, and a needy, passive-aggressive phone voice, in a single text under 200 characters.

## Run it

```sh
python3 main.py
```

Writes the text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), byte for byte, every run.
